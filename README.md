# UrbanFest 2027

Standalone static draft for the new UrbanFest 2027 website.

## Direction

This version deliberately continues the visual system of the 2026 Tilda site:
- Geologica typography
- palette: #261123, #4f364b, #cabad7, #f7e7de, #db3e1d
- pill buttons and circular motifs
- poster-like compositions rather than generic conference cards
- a large "How it was" section for guests, speakers and partners

## Current status

- 2027 speakers/program/workshops are placeholders until confirmed.
- Archive photos are temporarily referenced from the published 2026 Tilda site. Before production they should be copied into this repository and optimized locally.
- EN is the visual prototype. SR/RU content can be added after the structure is approved.
- Registration and venue are placeholders.

Open `index.html` directly in a browser.
